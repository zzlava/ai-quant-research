# 全 A 股价值排序基线评审

## 结论

数据里程碑通过，策略里程碑不放行实盘。

全市场点时派生股票池、行情与严格初始财报/每日估值可以组成可复现研究快照。价值排序在 5/20 日截面 IC 上为正且跨 2022、2023、2024 三年同方向；但是当前 8 万资金、最多 3 个仓位、固定 20 日持有的组合实现收益低、回撤高、Sharpe 低，仍只是研究基线。

## 下一里程碑

1. 建立按 `market_snapshot + fundamental_snapshot + config + date` 寻址的特征缓存，并为 IC 输出交易日进度；当前完整 IC 约 98 分钟，不适合快速迭代。
2. 在不调参拟合本窗口的前提下，先研究组合构造：扩大持仓数、行业/个股集中度上限、换手与容量约束，再做独立留出期验证。
3. 保留价值为主方向；质量/改善只作准入底线。不要因总体 IC 为正而继续堆叠弱因子。
4. 增加可投资基准（含股息或全收益指数）和现金/风险自由收益对照。
5. 未经留出期、参数稳定性和容量测试，不进入模拟盘/实盘候选。
