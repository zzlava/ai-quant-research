# 全 A 股防御价值候选策略 v3

## 假设

v1 的开发期组合收益为 -5.29%，v2 把负向趋势 IC 直接改成反转权重后进一步降至 -12.59%。v3 因此不再押注趋势方向，而把趋势仅作为极端下跌排雷；可重复的主要正向证据集中在价值，规模和完整机构持仓只承担用户要求的连续降权。

## 排名与门槛

```text
alpha = 40% 价值
      + 20% 质量
      + 10% 盈利改善
      + 15% 流通市值
      + 15% 已知的非个人前十大流通股东代理
```

- 原趋势延续分不进入 alpha；低于 15 分时拒绝，避免直接接极端下跌的“价值陷阱”。
- 流通市值越小，得分越低，但不使用事后市值硬切点。
- 完整 PIT 股东披露中非个人持股代理越低，得分越低；来源缺失保持 unknown，该分量从该股票分母移除，绝不填 0 或 50。
- 质量与盈利改善均设 30 分底线；attention、crowding 与 execution 继续作为负向风险项，其中 attention 惩罚提高。
- 仍用当时可见的沪深普通 A 股、ST/停牌/上市不足 250 日/20 日平均成交额不足 1 亿元排除，8 万元、最多 10 股、等权、固定持有 20 日。
- 没有合格的 PIT 行业历史，因此不伪造行业中性；相关性上限从 0.75 收紧为 0.70，作为价格行为层面的聚集约束。

## 研究边界

这是 2022–2024 开发期候选，必须先通过开发期组合与分年度稳定性检查。此前查看过的 2025+ 数据永久不能作为 v3 的干净 OOS；即使开发期改善，也只能冻结后等待新的未见前瞻窗口。

## 开发期结论

该假设已被否决。2022-07-01..2024-12-31 的组合模拟收益为 -7.60%，年化 -3.10%，Sharpe -0.325，最大回撤 -16.71%；96 笔已平仓交易的胜率 45.83%，profit factor 0.748，含佣金、印花税和滑点的交易成本为 2,018.23 元。它优于直接反转的 v2，但仍弱于 v1，不能进入冻结或样本外阶段。

连续创建更多权重版本会放大开发样本过拟合，因此本里程碑到此停止。下一阶段应先增加独立的因子分组收益、行业暴露和成交归因诊断；在没有合格 PIT 行业历史前，不得用当前行业标签重写历史组合。
