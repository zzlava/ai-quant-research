# 本轮研究计划停止规则

截至 2026-08-27，本轮没有得到可部署、可确认的优势：

- 第一层新 epoch 恢复反事实仍违反 -20% 最大回撤红线，Calmar 未达 0.5；
- 第二层财务排雷有描述性改善，但低波倾斜没有明显胜过安全随机组合；
- 因子家族统计功效为 `not_evaluable`；
- DSR 因历史试验台账不完整、trial 不可比，不能给数值。

因此部署决定为 `no_go`。目标架构保留为“宽基 ETF 核心 + 经验证风险层 + 可选卫星”，
但当前风险层和卫星层都未达到开放条件，30%/60%/90% 档位均不授权。

为避免跨轮次多重检验，本合同冻结个股 alpha 搜索至不早于 2028-08-27。期间允许
PIT 数据维护、被动记录新的冻结 OOS、ETF 成本/跟踪误差数据工程和修复已证实的工程
错误；不允许新因子、权重或 sleeve 搜索，也不允许事后翻案。

任何提前重启都必须出现醒目的人工确认，记录原因并创建新的 trial family、预注册和
全新未消费评价窗；系统不得自动重启，已消费 OOS 永久不可复用。

只读验证：

```bash
PYTHONPATH=src .venv/bin/python -m app.cli verify-research-plan-stop-rule --repo-root .
```
