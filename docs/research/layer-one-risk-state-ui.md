# 第一层风险状态 UI（E9b-2 前端）

研究仪表盘只读/人工操作面。**不可交易**。消费 E9b-1 `GET/POST /api/layer-one/*`；不接评分、回测、订单或券商。

## 行为摘要

- 应用加载立即拉取 `GET /layer-one/risk-state`；每次成功变更后刷新；**若 POST 成功但刷新失败则作废本地状态并进入 fail-closed 横幅**
- 全宽横幅置于仪表盘标题之上：API/完整性错误、未初始化、风险锁定均为失败关闭（有效预算 0%）；已初始化且未锁定仅显示研究状态，并固定 `ready_for_trading=false` / `ready_for_orders=false`
- 面板「第一层风险控制（研究/人工操作）」与排名/回测视觉隔离；变更须非空操作者/原因/`data_snapshot_id` + 精确确认短语
- 初始化 / 人工上限 / 解锁申请 / 部署证据（折叠）/ 审计只读（最多 20 条）
- 时间戳一律 `new Date().toISOString()`；绑定合约 id 与后端磁盘一致

## 明确非目标

- 声称可交易 / 可下单；绿“安全”态；自动初始化或自动升档；修改冻结 research JSON；改后端（除非类型不匹配阻塞 UI）
