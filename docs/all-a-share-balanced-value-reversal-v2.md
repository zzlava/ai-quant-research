# 全 A 股均衡价值反转候选策略 v2

## 来源与状态

v1 在 2022-07-01..2024-12-31 开发期组合模拟中收益 -5.29%、Sharpe -0.216。20 日信号日 IC 显示价值为稳定正向，中期趋势延续为稳定负向，因此 v1 保留为失败基线，v2 建立独立配置。v2 仍是开发期假设，不是可交易策略。

## 排名

```text
alpha = 30% 价值
      + 25% 中期反转（100 - 原趋势延续分）
      + 15% 质量
      + 10% 盈利改善
      + 10% 流通市值
      + 10% 已知的非个人前十大流通股东代理
```

质量和改善仍有 30 分底线，主要承担排雷。流通市值越小得分越低。股东代理仅在完整 PIT 披露存在时进入分母；unknown 不填 0/50。其余股票池、8 万资金、最多 10 股、等权、20 日换仓/持有、0.75 相关性上限与 v1 相同。

## 验证边界

本版本由 2022–2024 开发证据产生。此前已经查看过的 2025+ 数据不能再作为本版本的干净 OOS。只有在冻结代码、配置、数据 snapshot、成本和评估协议后，等待新的未见前瞻窗口，才能做一次性 OOS。

## 开发期结论

该假设已被否决。2022-07-01..2024-12-31 的组合模拟收益为 -12.59%，Sharpe 为 -0.414，最大回撤为 -24.38%；2022 下半年、2023、2024 分别为 -11.84%、-6.83%、+6.36%，均弱于 v1 的对应切片。负向截面动量 IC 不能直接解释为可交易的全量反转权重，v2 不进入冻结或样本外阶段。
