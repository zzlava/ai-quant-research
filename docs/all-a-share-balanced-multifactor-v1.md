# 全 A 股均衡多因子候选策略 v1

## 状态与研究边界

这是旧纯价值策略之后的**全新候选假设**，不是对已消费 OOS 结果的补丁。旧策略、冻结协议和 OOS 产物保持不变。本策略在冻结新的开发期/验证期之前，不得使用 2025+ 已查看区间调参，也不得称为可交易策略。

## 排名公式

候选股先通过 ST、停牌、上市不足 250 个交易日和 20 日平均成交额不足 1 亿元的点时过滤。随后计算：

```text
alpha = 25% 质量
      + 15% 盈利改善
      + 10% 估值
      + 20% 120 日相对趋势
      + 15% 流通市值
      + 15% 机构/公司型持股代理（仅在该股票有完整证据时）
```

质量或盈利改善截面分低于 30 的股票记为不合格。拥挤、执行和注意力风险继续作为小幅扣分项。市值项按当日可得 `circ_mv` 做截面分位数：流通市值越小，得分越低，但不设置事后挑选的绝对市值阈值。

## “机构持仓”字段的准确含义

当前免费数据合同不能证明全市场的真实机构持仓总比例。本策略使用 Tushare `top10_floatholders` 披露中的以下代理：

```text
前十大流通股东中，holder_type 不属于“个人/自然人”的 hold_float_ratio 合计
```

它表示可审计的“非个人大股东支持度”，**不等于**基金、保险、券商等全部机构的总持仓。一个报告组必须恰好有 10 行、10 个不同股东、每行有明确 `holder_type`，每个 `hold_float_ratio` 位于 0–100%，并且比例合计不超过 100%。若同一公告内同名股东出现互相冲突的源值，或源比率超出语义范围，原始值和所有变体均被保留，但该报告组整体记为 unknown；系统不擅自修正、不挑选一条，也不回退到更旧披露。数据按公告日当日 23:59（Asia/Shanghai）保守可用。

开发期覆盖诊断证明该来源并非稳定全截面字段，所以 v1.1 将它改为有证据才生效的辅助项：已确认低支持度会拉低加权均分，已确认高支持度会提高加权均分；unknown 股票保留，机构项从该股票的权重分母中移除，绝不填 0 或 50。`ownership_proxy_known` 和当日覆盖率随特征保留，便于分组审计。完整覆盖证据见 `docs/research/all-a-share-balanced-multifactor-v1-ownership-coverage.md`。

## 组合集中度

现有行业字段不是点时行业历史，不能安全地用来做历史行业上限。v1 改用过去 120 个交易日、只含决策日前数据的调整收盘收益相关系数限制：任何新股票与已持有/待买股票的相关系数超过 0.75，或历史不足，均不建仓。这能降低同一产业链或同风格股票扎堆，但不冒充行业中性化。

## 数据绑定与运行前提

运行需要三个逐级哈希绑定的数据层：

1. 市场六表快照；
2. 精确绑定该市场快照的财务/估值 overlay；
3. 同时绑定上述市场和财务 snapshot id 的前十大流通股东 overlay。

需要设置 `AIQ_FUNDAMENTAL_DIR` 与 `AIQ_OWNERSHIP_DIR`。任何 hash、绑定、公告时点、完整股东组或截面覆盖不一致都必须失败关闭。

## 后续冻结协议

完成数据采集和开发期诊断后，先在未触碰的新验证区间冻结：因子定义、权重、阈值、换仓锚点、交易成本与相关性上限。之后只允许一次性 OOS 评估；失败时建立新版本并等待新的前瞻区间，不能回看同一 OOS 继续调参。
